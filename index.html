Política de Privacidade

Esta Política de Privacidade descreve como a extensão NOC BA Consulta trata as informações dos usuários.

Coleta de Dados

A extensão não coleta, armazena, vende ou compartilha informações pessoais dos usuários.

Uso das Informações

Os dados inseridos pelo usuário são utilizados exclusivamente para execução das consultas necessárias ao funcionamento da ferramenta.

Armazenamento Local

Algumas informações podem ser armazenadas localmente no navegador utilizando os mecanismos disponibilizados pelo Google Chrome (chrome.storage), apenas para melhorar a experiência de uso.

Compartilhamento

Nenhuma informação é compartilhada com terceiros.

Segurança

A extensão realiza apenas as operações necessárias para seu funcionamento e não envia dados pessoais para servidores externos.

Alterações

Esta política poderá ser atualizada periodicamente para refletir melhorias ou mudanças na extensão.

Contato
